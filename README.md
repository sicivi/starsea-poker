# 星海神域 · StarSea Poker

**3D开放世界卡牌策略游戏**

## 🎮 立即试玩

- **GitHub Pages**: https://sicivi.github.io/starsea-poker/
- **Gitee Pages**: https://sicivi.gitee.io/starsea-poker/

## ✨ 游戏特色

### 核心玩法
- **8人星海牌局**：完整德州扑克规则，多人AI对手
- **多种赌场游戏**：老虎机、百家乐、21点、轮盘、骰宝、赌马
- **星海币经济**：交易、贷款、追债、股市、税收、彩票

### 3D开放世界
- **五大分区**：星海牌宫、国会大厦、深渊牢笼、南极战争机器、星域星港
- **3D传送门**：主城四向光柱传送，穿越结界过场动画
- **分块加载**：15主题区块，相邻解锁，行走探索

### 深度系统
- **组织经营**：五级行会（乡会→帝国），人口/忠诚/战力
- **神话宠物**：五行灵兽养成/出战/产出/献祭
- **婚姻家庭**：相亲/彩礼/婚礼/生子/离婚
- **信仰神迹**：五行圣地/神迹庇佑/献祭反噬
- **NPC互动**：程序化动作库、对话系统、好感度

## 🚀 本地运行

```bash
# 方式1：直接打开
# 双击 index.html 即可开始游戏

# 方式2：本地服务
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 🛠️ 技术栈

- **Three.js** - 3D渲染引擎
- **Vanilla JS** - 无框架依赖
- **单文件架构** - 所有代码打包在一个HTML文件中
